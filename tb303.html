Pattern
Oct 0
Write ON: click a step, then play a note; the cursor advances.
Knobs: drag up / down (or use the mouse wheel), double-click = default value. In the grid: scroll or drag on a note to change its pitch, click Oct / Accent / Slide / Gate to toggle. Computer keyboard: middle row = white keys (A S D F… QWERTY / Q S D F… AZERTY), top row = black keys. Playing legato (overlapping keys) = slide. Space = Run / Stop.
